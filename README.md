# Fundamentals of Acoustics Notes

这是一个使用 **Typst** 编写的《Fundamentals of Acoustics》课程笔记仓库，内容基于米兰理工大学（Politecnico di Milano）**2025 Fall** 学期的同名课程。该笔记为准备考试而作，因此其内容可能不够详尽或系统，例如省略了课程的第六章节。

## 目录结构

- [Fundamentals of Acoustics Notes.typ](Fundamentals%20of%20Acoustics%20Notes.typ)：主笔记源文件（Typst）
- media/：图片等媒体资源

## 环境依赖

- Typst（用于编译 `.typ` → `.pdf`）
